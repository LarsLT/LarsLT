# dev/proposed/

Ideas we've discussed but aren't building yet. Park one here to sideline it
without losing the thinking.

One subfolder per idea: `proposed/<slug>/PLAN.md` (same template as `active/`,
but the Steps can stay rough — it's a sketch, not a commitment).

Tracked in git so the backlog is shared and reviewable.

- **Promote** to `dev/active/<slug>/` when work starts (`git mv`).
- **Delete** if we decide against it.

See `../README.md` for the full lifecycle.
